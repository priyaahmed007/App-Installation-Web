# 📱 Hero App — App Installation Website

Discover trending apps, explore app details, and manage your installations in one place.

🔗 **[Live Website](https://app-installation-web.vercel.app/)** · 💻 **[GitHub Repository](https://github.com/priyaahmed007/App-Installation-Web.git)**

## ✨ Features

- 🏠 Modern and responsive homepage
- 🔥 Trending apps showcase
- 📱 Browse apps and view detailed information
- ⭐ App ratings, downloads, and sizes
- 📥 Install and manage apps
- 📋 Installation history
- 🔗 Dynamic app details pages
- 📱 Responsive design for all devices

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS

## 🚀 Installation

**1. Clone the repository**

```bash
git clone https://github.com/priyaahmed007/App-Installation-Web.git
```

**2. Navigate to the project directory**

```bash
cd App-Installation-Web
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
